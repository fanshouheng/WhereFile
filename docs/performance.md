# 性能验证 · v0.1.2

2026-11-13，在同一台电脑比较 v0.1.1（`56869ea`）与本次优化。测试使用隔离的 WebView2 宿主、独立数据目录，1920×1080、DPR 1、AMD Radeon R9 380 / D3D11、WebView2 157；每阶段热身 5 秒、采样 10 秒。

| 测试场景 | v0.1.1 CPU / GPU | v0.1.2 CPU / GPU |
| --- | --- | --- |
| 无船，播放 | 1.91% / 21.00% | 1.09% / 7.75% |
| 2 个小船对象，播放 | 2.93% / 20.75% | 1.50% / 7.75% |
| 无船，暂停 | 2.07% / 19.00% | 0.43% / 0% |
| 2 个小船对象，暂停 | 2.28% / 18.86% | 0.20% / 0% |

CPU 为 8 个逻辑核归一后的宿主与 WebView2 进程树平均值，GPU 为相关进程最忙引擎的采样均值。测试小船通过正式页面的桌面消息创建，未连接真实桌面扫描器或原生小船窗口，因此这些数字反映海面与网页的开销，不能代表完整桌面软件在所有电脑上的占用。

海面与装饰约 30 次/秒绘制，小船运动和位姿消息约 60 次/秒更新；暂停后海面、装饰和位姿消息停止。画布分辨率、素材及小船亚像素移动保留。海浪着色器跳过无贡献的陆地、远海岸浪计算。其他应用最大化、全屏或锁屏时停止动画及桌面轮询。

运动检查覆盖不同帧率下的航程一致性、暂停、恢复、暂停时的键盘移动与靠岸，以及三套壁纸的水域边界。原始采样和隔离测试工具保存在本机被 Git 忽略的 `output/performance/`。
