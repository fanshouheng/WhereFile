# 动态壁纸主题制作

把主题做成一套协调的素材与行为：静态背景、可独立移动的物件、活动范围和运动方式。
沿用用户指定的风格；没有指定时从主题决定，不默认把所有场景做成海岸或二次元。

## 确定这次的交付

从用户要求与现有项目判断是新建主题、改素材、独立预览还是正式接入。主题、风格、用途已清楚就开始；缺少会改变结果的关键信息才询问。

先用几句话写清：

- 场景与气氛、画幅和观看视角。
- 主体细节的位置、物件能活动的连续区域、需要留给图标或文字的位置。
- 专属物件是什么、用什么方式移动、是否需要随航向转身。
- 背景里固定画哪些内容、哪些效果留给程序；交付到预览还是正式产品。

默认先在独立目录完成可审阅的主题；用户已要求正式接入时继续完成接入。只有做主题或预览时，不顺带修改桌面宿主、安装器、真实文件或线上部署。

## 制作背景与物件

1. 先看已有主题与实际渲染器。保留相机、光源、配色和材质的一致性，按构图确定运动区域。
2. 分开写背景和物件提示词，按需读取 [提示词与美术检查](references/art-direction.md)。物件不能画死在背景里；不要把程序要画的动态层重复烘焙进背景。
3. 使用当前可用、获授权的生图工具；需要生图时按工具环境读取 imagegen 等对应技能。沿用用户选定的服务，不把历史项目的供应商、模型、密钥位置当通用配置。先检查已有素材，复用可用结果。一次先验证一套搭配；基于具体缺陷做局部修正，避免无依据地成批重生成。
4. 透明输出可用时优先真 Alpha。需要色键时选物件本身没有的颜色。不得把棋盘格图片当透明图，或对含粉色的物件机械去品红。
5. 保存原图和生成提示词，另输出运行素材。物件缩到约 90px 仍需辨识，留出旋转与细部空间；在白、深灰、实际背景上看边缘。

附带工具使用 Python 与 Pillow。`scripts/prepare_sprite.py` 可以裁切已有 Alpha PNG、统一留边，并生成浅/深底检查图；可选处理纯绿或品红背景。纯色抠图还需 NumPy/OpenCV，优先用现有环境，缺依赖时明确说明。

```powershell
python -X utf8 "<skill>/scripts/prepare_sprite.py" object-source.png --out object.png --size 384
python -X utf8 "<skill>/scripts/prepare_sprite.py" object-green.png --out object.png --key green --size 384
```

`--despill` 只在确认物件不含该色时使用。半透明烟雾、玻璃或与幕布同色的物件不适合此工具，改用透明生成或专门的蒙版。每次输出使用新路径，工具不覆盖已有文件。

## 组装与验证预览

用最终背景和最终透明物件做预览，不用旧图或占位物件代替。以 [主题配置示例](assets/theme.example.json) 为起点，路径相对于配置文件；活动区域为整张背景的归一化矩形 `[左, 上, 右, 下]`。

```powershell
python -X utf8 "<skill>/scripts/build_preview.py" theme.json --out preview
```

工具复制素材并生成可直接打开的 `preview/index.html`，无需服务器或 npm。提供暂停、速度、物件大小和名称开关，支持减少动态偏好及后台暂停。`motion` 可选 `float`（保持原始朝向）、`heading`（随航向旋转）、`spin`（缓慢自转）、`sway`（小幅轻摆）；`forward_degrees` 是物件原画头朝屏幕右方顺时针的角度，只对 `heading` 有效。

- 小舟可轻漂；陨石可缓慢旋转；龙卷风应保持竖直并轻摆。需要立体转向的船不宜把整张图旋转，使用多方向图集或产品已有转向逻辑。
- 预览按整幅图等比显示，物件和标签在活动区域内留边；复杂地形、多个不连通区域需要产品的遮罩或航行系统，不能把矩形预览当碰撞验证。
- 打开预览验证完整运动周期、多个物件相位、暂停与恢复、速度为零、缩放、窄屏和减少动态偏好。截图检查构图、色边、标签和物件是否进入不该活动的区域。
- 用户只要素材或提示词时，按其范围交付，不强制新增预览。生成工具不可用时交付已完成部分并标明素材待生成，不声称完成。

## 接入与交付

需要接入 WhereFile 时才读 [WhereFile 适配](references/wherefile.md)；其他项目读取其实际接口，不预设主题注册表、路径、分辨率或海浪算法。

正式接入需验证背景坐标、活动边界、物件朝向、暂停和性能；独立浏览器预览只证明设计可展示。不要据此声称系统壁纸、桌面文件联动或安装包已经更新。

交付背景、透明物件、提示词、主题配置和需要的预览，给出实际路径以及验证状态。官网仅展示尚未接入的主题时，简单标注“尚未上线”；只有用户要求时发布。
